# Hello — about this site

Welcome. This is my corner of the internet — half **blog**, half **portfolio**.

I'm a full-stack engineer (Java + Vue) who spends most of my time these days putting LLMs into real products and working on data collection, cost reduction, and anti-bot research. I write here about the things I actually built and the trade-offs behind them.

## What you'll find

- **[Projects](/en/projects)** — the work worth explaining in depth: an LLM tool-use agent, a cost-cutting data pipeline, a high-frequency scheduler, and more.
- **Blog** — technical practice and post-mortems. Most in-depth posts are in Chinese for now; English versions are being added over time.

## How it's built

This site is open source, built with [VitePress](https://vitepress.dev) and deployed on GitHub Pages. It's bilingual (中文 / English) — switch languages from the top-right menu.

Thanks for stopping by.
