# 关于我

我是一名全栈工程师，主要用 **Java（Spring Boot）+ Vue** 做事，最近的重心在**把 LLM 落进真实业务**，以及**数据采集的降本与反爬**。

比起「会用什么框架」，我更在意两件事：

1. **能不能独立把一件事从头做到上线**——后端、前端、部署、踩坑排查，整条链路自己扛下来。
2. **技术决策有没有证据**——该省的地方用数据证明能省，该放弃的地方也用实验说清楚为什么绕不过去。一次被证据支撑的「不做」，和一次成功的「做」同样重要。

## 我现在感兴趣的方向

- LLM Agent / Tool-Use 在业务系统里的可靠落地（安全边界、成本控制、幻觉治理）
- 多模态模型在审核、监控类场景的工程化
- 数据采集、反爬与风控对抗背后的网络分层原理

## 这个站是什么

一半是**博客**——记录做过的技术实践、踩过的坑、想清楚的问题；一半是**作品集**——把值得讲的项目讲明白。它本身也是开源的，用 VitePress 搭、部署在 GitHub Pages。
